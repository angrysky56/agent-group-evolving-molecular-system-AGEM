# Answer key — quantum mind and the genesis of the code

The one corpus here whose thesis is **under test rather than being validated**.
A MUS is a good outcome: it names the commitment to drop.

## What the engine should conclude

**The strong (teleological) synthesis fails.** "The genetic code was optimized
*for* consciousness" is incoherent on standard evolutionary theory: selection
*for* a trait requires that trait to be causally responsible for differential
reproductive success at the time of selection, and consciousness postdates the
code by roughly three billion years. Expected as `teleological_bridge_fails`.

**The weak (enabling) synthesis survives.** "The code was optimized for
error-robustness; robustness permitted open-ended complexity; consciousness is
downstream of that complexity" is consistent. This is selection *of*, not
selection *for*, and it is a perfectly respectable claim. Expected in
`mustNotFind` — it must come back SAT.

**Orch-OR is empirically constrained, not refuted.** Tegmark's decoherence
estimate is 10+ orders of magnitude short of what Orch-OR needs; Hagan, Hameroff
and Tuszyński dispute the model and get longer times. The corpus states both, so
a correct run reports **positions-incompatible with an open empirical question**,
not a settled contradiction. Getting this distinction right is the whole test of
the attribution fix.

**The substrate bridge collides with multiple realizability** — and this is the
first **cross-corpus** MUS in the set. If AGEM finds it by pulling
`multiple_realizability` from the persisted theories-of-mind run rather than
re-deriving it from this corpus text, the claim graph is doing its job.

## The result worth having

Not a verdict. Enumerate the maximal satisfiable subsets and report **the largest
MSS containing `consciousness_downstream_of_complexity`**. That is the strongest
defensible version of the synthesis, with the dropped commitments named
explicitly.

A precisely bounded version of your idea, with the price of each remaining
commitment itemised, is worth considerably more than a vindication. It's also the
only output of this corpus that another person could argue with.

## Two tripwires

**`code_optimization_pluralism`.** Error-minimization, stereochemistry,
coevolution and frozen accident are *usually presented as rivals* but are largely
compatible — the code could be a frozen accident, seeded stereochemically, later
refined for robustness. If AGEM reports a MUS here it has read rival-framing as
logical opposition. Same failure as ToM's HOT/HOP.

**`enabling_bridge_survives`.** If this comes back contradictory, then
`teleological_bridge_fails` is meaningless — it would have fired on anything, and
the engine has not learned selection-for from selection-of.

## Known conflict to resolve before a joint session

`ontology.json` aliases `substrate_independence` → `multiple_realizability` so
the cross-corpus link resolves. **The theories-of-mind corpus deliberately keeps
them apart** (distinction #10: multiple realizability is a claim about kinds,
substrate independence is a thesis about what consciousness requires).

These two ontologies disagree. That is not an oversight — it is the first real
instance of the problem that will dominate cross-corpus work: **two fields using
one word for two things.** Decide before running them together:

- keep them distinct and add an explicit bridging axiom
  (`multiple_realizability(x) -> possible(substrate_independence(x))`), **or**
- merge and accept that ToM distinction #10 becomes untestable in joint sessions.

The first option is right. It's written here rather than fixed silently because a
silent fix is how the last two wrong verdicts happened.
